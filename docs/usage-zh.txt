【用法】
把视频 / 音频（或整个文件夹）拖进窗口就会入队，也可以点「媒体转换器」页的按钮添加。
上方四个页签切换功能：PSP 记忆棒 / 媒体转换器 / DY 数据库 / PSP 游戏。

【快捷键与手势】
滚轮在画面或控制条上可以调音量；双击画面进全屏，Esc 或再双击退出全屏；
右键画面切换「裁切 / 适合窗口」。

【转换口径】
视频 → {profile}，竖屏自动左转 90°，同名 .THM 缩略图，扩展名固定大写 .MP4。
      设置页里「视频格式」拆成两个下拉：左边选编码格式，右边选码率。
      左边七个基座（分辨率 + Profile 已经锁死，避免拼出播不了的组合）：
        480×272 · H.264 Baseline   码率 600~2400k（16:9 首选）
        480×272 · H.264 Main       码率 600~2400k（16:9，宽 ≤480 两种 Profile 都认）
        480×240 · H.264 Baseline   码率 600~2400k（2:1 矮屏，上下带黑边）
        480×240 · H.264 Main       码率 600~2400k（2:1 矮屏，上下带黑边）
        720×480 · H.264 Main       码率 800~3000k（4:3 满屏，这里档位最多）
        640×480 · H.264 Main       码率 800~3000k（4:3，同码率更省像素）
        320×240 · MPEG-4 SP        码率 250~800k（800k 已到编码上限）
      编码实测（6.61 Pro-C，6 分辨率 × 3 编码全矩阵真机跑过）：
        ┌──────────┬────────────┬──────────┬─────────────┐
        │ 分辨率    │ H.264 Base │ H.264 Main│ MPEG-4 SP   │
        ├──────────┼────────────┼──────────┼─────────────┤
        │ 320×240  │     —      │    —     │  ✔ 能播     │
        │ 480×240  │  ✔ 能播    │ ✔ 能播   │  播放错误   │
        │ 480×272  │  ✔ 能播    │ ✔ 能播   │  播放错误   │
        │ 640×480  │  不兼容    │ ✔ 能播   │  不兼容     │
        │ 720×480  │  不兼容    │ ✔ 能播   │  不兼容     │
        │ 640×360  │  不兼容    │ 不兼容   │  不兼容     │
        │ 640×204  │  不兼容    │ 不兼容   │  不兼容     │
        └──────────┴────────────┴──────────┴─────────────┘
        两条规律：
          ① 宽 ≤480 时 Baseline / Main 都能播；宽 >480（640 / 720）必须 Main，Baseline 一律不兼容
          ② 白名单严格限定在 320×240 / 480×240 / 480×272 / 640×480 / 720×480，
             640×360、640×204 这种非标尺寸换任何编码都进不去
        MPEG-4 只有 320×240 能真解码，其他尺寸掌机能识别但播放报错。
      码率实测：官方标的视频 768k 上限是假的，1200k / 2400k 真机都能正常播放，
            所以档位码率按实测放开；MPEG-4 在 320×240 下到 800k 左右就饱和，
            再往上设多少编出来都一样大，没有提升空间。
      参数：Baseline 档钉死 aud=1 / cabac=0 / 8x8dct=0 / weightp=0 / bframes=0 / ref=1；
            Main 档只关 B 帧（特性关光了 x264 会降级成 Constrained Baseline，
            宽 >480 的分辨率就不认了）。
      实测结论：掌机只认 <盘>\VIDEO 下的文件，放进 MP_ROOT\100MNV01 或 100ANV01
      一律报「不兼容的数据」——同一个文件换个位置就能播，所以别再往 MP_ROOT 放。
      真正的限制是「视频条目总数」，不是目录个数：
        VIDEO 里（含所有子目录）累计约 1000～1024 个视频就到头，超出的按遍历顺序不显示。
        实测 VIDEO\01 放 1000 个 → 掌机显示 999+（999 是计数显示上限，不是丢了文件）；
        VIDEO\02 放 900 多个 → 只显示 24 个，1000 + 24 ≈ 1024 正好顶满配额。
        跟目录几个、名字多长都无关，只看全卡视频总数。
        所以一卡别塞太多，按 1000 个以内规划最稳，想让后面的目录也显示就得先减前面的。
      「视频存放位置」只有两项可选，且都落在 <盘>\VIDEO 下：
        VIDEO 目录（默认）—— 全部平铺，不建任何子目录，最稳
        VIDEO 目录 + 按作者分目录 —— 按作者归档，一个作者一间目录，不合并
      MP_ROOT 编号目录那条路已经彻底去掉，选过它也会自动回到 VIDEO。
      「PSP 记忆棒」页的目录读取在后台跑，根部先显示「正在读取记忆棒…」，读完自己填进去。
音频 → {afmt}（在设置里选 MP3 / WMA / WAV），本身格式相同就直接复制。
先转进临时目录（{temp}\video 与 {temp}\music），完成后再拷进记忆棒，慢速卡也不卡住。
记忆棒目录：{card}（视频进 VIDEO，音乐进 MUSIC）。
