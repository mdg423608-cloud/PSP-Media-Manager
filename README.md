# PSP Media Manager

一款为 **PSP-3000（6.61 PRO-C）** 做的媒体管理与视频转换工具，Windows 图形界面，基于 tkinter + ffmpeg。

把电脑上的抖音视频、本地影片批量转成 PSP 能直接播放的格式，按作者分目录写进记忆棒，并在程序里直接预览、播放、管理卡上的内容。

---

## 功能

### 视频转换
- 一键批量转成 PSP 兼容的 MP4（H.264 + AAC），按分辨率与编码矩阵自动选择可用编码基座
- 输出前清空元数据（`-map_metadata -1` + bitexact），避免 mov muxer 写出 XMP uuid box 导致掌机报「不兼容的数据」
- 自动裁剪/缩放、自动算码率，超限自动降档
- 转换进度、剩余时间、失败清单，可随时停止

### 音频
- 视频音轨抽离转 MP3，码率与采样率可选
- 码率/采样率按 PSP 播放器实测上限约束

### 数据库导入（抖音）
- 读取抖音桌面端本地数据库，按作者归类
- 作者列表 / 视频列表两级视图，缩略图缓存
- 从任意一条起播、随机播放、循环重播

### 记忆棒管理
- 扫描 `<盘>:\VIDEO`，校验文件名、扩展名、目录数量
- 目录总数上限 **14**，超限提示合并
- 内置播放器（ffmpeg 解码 + ffplay 出声），支持变速、全屏、音量条
- 音乐频谱可视化，多种特效可切换

## PSP 兼容性矩阵（实测）

| 分辨率 | 可用编码 |
|---|---|
| 320×240 | MPEG-4 SP |
| 480×240 | H.264 **Baseline** / **Main** |
| 480×272 | H.264 **Baseline** / **Main** |
| 640×480 | H.264 **Main** |
| 720×480 | H.264 **Main** |
| 640×360 | 不兼容（任何编码均无法播放） |
| 640×204 | 不兼容（任何编码均无法播放） |

码率上限：视频 `3400 kbps`，音频 `128 kbps`。

---

## 硬规则

1. 视频必须放在 `<盘>:\VIDEO` 目录（或其子目录）下
2. 扩展名必须是大写 `.MP4`
3. `VIDEO` 累计条目数约 **1000～1024** 上限，超过掌机只显示一部分
4. 目录数过多会导致掌机显示不全，本程序把总数限制在 **14** 以内

## 安装

### 安装版
下载 `PSP Media Manager v1.0.3 Setup.exe`，双击安装，默认装到 `%LOCALAPPDATA%\Programs\PSP Media Manager`，无需管理员权限。

### 绿色版
解压后直接运行 `PSP Media Manager.exe`，同目录 `_internal\bin` 下已带 ffmpeg / ffprobe / ffplay。

> 首次启动后请等约 10 秒再点第一条视频：程序在后台预热 ffplay，预热完成后再点就是瞬时响应。

---

## 运行环境

- Windows 10 / 11（x64）
- 免安装 Python：安装包内已打包 Python 3.9 运行时
- 依赖组件：ffmpeg 9.0.2、tkinterdnd2、Pillow

## 版本历史

### v1.0.3
- **修复**：点视频切播、循环重播时「正在打开」停顿 2–3 秒
  - 根因：打包（PyInstaller windowed）环境下 ffplay 冷启动要 2.2–6 秒，热态仅 24 ms
  - 修法：启动即后台预热 ffplay、音频进程异步启动、两次 ffprobe 合并为一次并加缓存、首帧抽取异步节流
- 修复：windowed 父进程下子进程因无有效 stdin 卡住不返回（全项目 Popen 补 `stdin=DEVNULL`）
- 新增：`--lagtest` 自检通道，可在打包环境内输出完整延迟报告

### v1.0.2
- 优化：取消非必要的阻塞式进程等待，切视频改为快速终止
- 优化：ffprobe 双次探测合并

### v1.0.1
- 首个可安装版本（Inno Setup 打包，onedir 分发）
